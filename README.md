# Visualisation-project
Для этого проекта я взяла этот [датасет](https://www.kaggle.com/datasets/valakhorasani/gym-members-exercise-dataset). Он содержит информацию о различных физических параметрах человека (пол, рост, вес и т.д.) и информацию о его тренировках (средний пульс, длительность тренировки, сожженные калории и пр.)

## Структура проекта
Этот проект представляет собой интерактивный блокнот, в котором представлены анализ и визуализация данных из датасета. В частности, ислледуется влияние некоторых факторов на количество сожженных во время тренировки калорий.
